# Standflow – Issue Tracker

This is the official issue tracker for [Standflow](https://standflow.app), a standing desk timer that lives in your Mac's menu bar and reminds you to alternate between sitting, standing, perching, and moving.

## Before opening an issue

Many common problems (notifications not showing, the menu bar icon missing, the timer moving on without asking) have a quick fix on the [Support page](https://standflow.app/support).

## Report a bug or request a feature

1. Search the [existing issues](https://github.com/standflowapp/standflow/issues) to see if someone already reported it. If so, add a 👍 or a comment with your details.
2. If not, [open a new issue](https://github.com/standflowapp/standflow/issues/new/choose) and pick **Bug report** or **Feature request**.
3. For bugs, include your macOS version, your Standflow version (Settings → About), and the steps to reproduce the problem. Screenshots help a lot.

Please don't include personal information in issues: they're public.
